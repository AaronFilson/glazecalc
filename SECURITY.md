# Security

If you find a security problem in Glazecalc, please tell us privately before you make it public, either way:

- Email **security@glazecalcapp.com** (also listed in [security.txt](https://glazecalcapp.com/.well-known/security.txt)).
- Or use GitHub's private reporting: **Security → Report a vulnerability** on this repository
  ([report one](https://github.com/AaronFilson/glazecalc/security/advisories/new)).

Say what you found, where, and how to reproduce it. Please do not read or change other people's data.

## Supported versions

Glazecalc is one site, [glazecalcapp.com](https://glazecalcapp.com), deployed from `master`. Fixes go to `master`
and from there to the site; there are no older versions kept running to patch. A report about a release (1.0.0 or
later) is checked against what the site runs now.

Glazecalc is a free project run by one person, so there is no bounty, but reports are read, answered and
fixed as quickly as possible.
Problems that are not security-sensitive can go to the [issue tracker](https://github.com/AaronFilson/glazecalc/issues).
